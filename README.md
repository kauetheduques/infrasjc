# InfraSJC | Cidade preparada para a chuva

Página web informativa sobre **alagamentos e falta de infraestrutura em São José dos Campos (SP)**, desenvolvida como projeto multidisciplinar da faculdade.

🔗 **Site:** https://kauetheduques.github.io/infrasjc/

## Sobre o projeto

Quando a chuva chega, a cidade precisa estar preparada. O InfraSJC mostra por que a água acumulada é mais do que um transtorno, quais são as causas urbanas, ambientais e estruturais dos alagamentos e quais soluções de infraestrutura podem ajudar a prevenir o problema.

A página apresenta:

- **Chuva em tempo real:** dados atuais de São José dos Campos, vindos da API Open-Meteo
- **O problema:** o impacto dos alagamentos no dia a dia
- **Dados:** registros que mostram o problema na cidade
- **Causas:** fatores urbanos, ambientais e estruturais
- **Solução:** infraestrutura inteligente, verde e preventiva
- **Impacto:** como uma cidade mais resiliente protege as pessoas
- **Participação:** como a informação e o envolvimento ajudam a cidade
- **Fontes e referências**
